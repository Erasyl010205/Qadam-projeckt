# Qadam Code

Қазақ тіліндегі бағдарламалау платформасының алғашқы жұмыс істейтін веб-нұсқасы. Интерфейс HTML, CSS және JavaScript арқылы жасалған. Bootstrap 5.3.8 дайын кластарымен бірге жеке дизайн стилі, Lucide белгілері қолданылды. Bootstrap пен Lucide файлдары жергілікті assets бумасында, Manrope қарпі Google Fonts арқылы жүктеледі; желі болмаса жүйелік қаріп қолданылады.

## Іске қосу

Node.js 20 не одан жаңа нұсқа керек. Жоба каталогында:

```sh
npm run dev
```

Терминалда көрсетілген жергілікті мекенжайды браузерде ашыңыз. Жұмысқа қабілеттілік тексерулері:

ES модульдер үшін сайтты HTTP сервері арқылы ашыңыз; index.html файлын file:// арқылы тікелей ашпаңыз.

```sh
npm run check
```

Тексеру JavaScript синтаксисін, жергілікті прогрестің сақталуын, бүлінген деректен қалпына келуді, XP-дің бір сабаққа бір рет берілуін және 16 сабақтың құрылымын қамтиды.

## Осы нұсқадағы мүмкіндіктер

- Басты бет, оқу панелі, курстар және бейімделетін интерфейс.
- Python және Java бойынша сегіз сабақтан тұратын екі курс.
- Түсіндірме, мысал, практика тапсырмасы және білімді тексеру сұрағы.
- Дұрыс жауапқа XP беру және бір сабаққа қайта XP бермеу.
- Браузерде сақталатын код нобайлары, жергілікті профиль мен оқу прогресі.
- Рейтинг, достар және жарыс идеяларын көрсететін анық белгіленген демо интерфейстер.

Атты енгізу тек осы браузердегі жергілікті профильді өзгертеді. Бұл серверлік аккаунт, тіркелу немесе қауіпсіз аутентификация емес. Құпиясөз жиналмайды. Деректер localStorage ішінде сақталады; басқа құрылғыға көшпейді. «Деректерді тазалау» жергілікті прогресті өшіреді.

Сабақтың аяқталуы білімді тексеру сұрағына дұрыс жауап берілгенін білдіреді. Кодты сақтау оның орындалғанын немесе дұрыс екенін білдірмейді. Python/Java орындалуы, автоматты код тесттері, нақты достар, WebSocket жарыстары және серверлік рейтинг әлі қосылмаған. Демо рейтинг нақты қолданушылар дерегі емес.

## Құрылым

```text
dist/
  index.html       HTML кіріс нүктесі
  app.js           Маршруттар мен интерактивті интерфейс
  style.css        Дизайн мен бейімделетін орналасу
  data.js          Қазақша сабақтар және бөлек демо рейтинг
  state.js         Жергілікті профиль, прогресс, код нобайлары
  assets/          Жергілікті ресурстар
scripts/
  serve.mjs        Әзірлеу сервері
  state.test.mjs   Прогресс және сабақ деректерінің тесттері
.env.example       Болашақ сервер баптауларының үлгісі
```

## Статикалық жариялау

`dist` бумасының мазмұнын статикалық хостингке жүктеңіз. Жинақтау қадамы қажет емес. Cloudflare Pages-та жоба құру кезінде output directory ретінде `dist` таңдаңыз. Файлдарды орналастыру осы кезеңдегі статикалық сайтты ғана жариялайды.

## Келесі кезеңдер

Нақты код орындау үшін бөлек оқшауланған sandbox керек. API оның кілтін серверде сақтап, уақыт, жады және шығыс көлемін шектеп, нәтижені құрылымдалған жауап ретінде қайтаруы тиіс. Қолданушы кодын негізгі API серверінде орындамаңыз.

Қауіпсіз аккаунттар, D1 миграциялары, серверлік құқық тексерулері және XP транзакциялары — кейінгі сервер кезеңі. Жарыстарға Durable Objects/WebSocket, серверлік таймер, жасырын тесттер және нәтижені қайталап есептемеу қажет. `.env.example` болашақ интеграцияларға орын қалдырады; ағымдағы статикалық сайт ол мәндерді пайдаланбайды.

Нақты sandbox, авторизация немесе multiplayer интеграциясының тесттері осы нұсқада жүргізілмейді: олардың сервері әлі іске асырылмаған.
