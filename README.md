# Qadam Code

Қазақ тіліндегі Java және Python оқу платформасы. HTML, CSS, ES Modules JavaScript, Bootstrap 5.3.8 және Lucide қолданылады. Кітапхана файлдары assets ішінде; Manrope қарпі жүктелмесе жүйелік қаріп қолданылады.

## Іске қосу

Windows-та ZIP архивін толық шығарып, START-QADAM.cmd файлын екі рет басыңыз. Node.js орнатылған болса, сервер бос портты таңдап, сайтты браузерде ашады. Сервер терезесін ашық қалдырыңыз.

Node.js 24 немесе жаңарақ нұсқасы орнатылған ноутбукта package.json тұрған каталогта:

    npm run dev

Браузерден http://127.0.0.1:4173 ашыңыз. Жергілікті іске қосуға npm install қажет емес: HTML/CSS/JavaScript файлдары жоба ішінде, ал ойын сервері Node.js-тің кірістірілген SQLite модулін пайдаланады. Жариялауға арналған жинақты құру үшін npm ci қажет.

## Онлайн пинг-понг · 1v1

«Шайқастар → Пинг-понг» бөлімінде атыңды жазып, бөлме аш. Алты таңбалы кодты немесе шақыру сілтемесін досыңа жібер. Екінші ойыншы сол сайтқа басқа ноутбуктен кіріп, кодпен қосылады. Басқару: W/S немесе жоғары/төмен пернелері; телефонда алаңды сүйреуге болады. Бірінші болып 7 ұпай алған ойыншы жеңеді. Екі ойыншы да «Тағы ойнау» басса, жаңа матч басталады.

Доптың қозғалысын, соқтығысуларды, ұпай мен жеңісті сервер есептейді. Ойыншы тек өзінің қалақша бағытын жібереді. Екі браузер бір серверге қосылуы керек: басқа ноутбуктағы localhost — осы ноутбуктің сервері емес. Интернеттен ойнау үшін жарияланған сайттың сілтемесін пайдаланыңдар. Сайт жеке болса, әр құрылғыда рұқсаты бар ChatGPT аккаунтымен кіру қажет.

Байланыс 3 секундтан ұзақ үзілсе, матч кідіреді; қайта қосылғанда доп қайта санақтан кейін беріледі. Әр бөлменің әрекетсіздік мерзімі — 30 минут. Бөлме коды шақыруға арналған; қалақшаны басқару үшін браузердің жеке ойыншы токені керек. Токен сілтемеге қосылмайды. Python тесті бөлек қойындыда сақталған.

Жергілікті бөлмелер .qadam-data/pong.sqlite ішінде, жарияланған сайттың бөлмелері Cloudflare D1 ішінде сақталады. Бұл екі дерекқор бөлек. SQL миграциялары сервер іске қосылғанда немесе Sites жариялау кезінде орындалады.

## Оқу мазмұны

Python курсында 8, Java курсында 13 тақырып бар. Java-да класс пен объектіден кейін инкапсуляция, мұрагерлік, абстракт кластар, интерфейстер және полиморфизм оқытылады. Курстың есептік оқу уақыты сабақтардың ұзақтығынан автоматты есептеледі; нақты қарқын оқушыға байланысты.

Әр сабақта:
- оқу мақсаттары мен алдын ала білу керек ұғымдар;
- түсінікті теорияның 4 бөлімі;
- нақты нәтижесі мен қадамдық талдауы бар 2 мысал;
- жиі кездесетін қателер және түзету жолдары;
- 3 жаттығу, бөлек ашылатын ишара және толық үлгі шешім;
- негізгі тұжырымдар;
- әр жауабы түсіндірілетін 3 білім сұрағы;
- ресми Python/Java құжаттамасына сілтеме бар.

Барлығы: 21 сабақ, 84 теория бөлімі, 42 талданған мысал, 63 жаттығу, 63 білім сұрағы. Әр теория бөлімінің қысқа түсіндірмесі бірден көрінеді, қосымша ережелер «Толығырақ оқу» ішінде ашылады.

Сабақ барлық үш сұрақ дұрыс болғанда аяқталады. XP бір сабаққа бір рет беріледі. Бұрынғы сабақ ID-лері өзгермегендіктен, сақталған прогресс пен нобайлар үйлесімді. Әр жаттығу код алаңында өз тапсырмасымен ашылады және нобайы жеке сақталады.

## Тексеру

    npm run check

Тексерулер мазмұнның толықтығын, бағалау логикасын, XP, нобай кілттерін және сақтау/қалпына келу әрекеттерін тексереді. Бұрын аяқталған Java сабақтары жаңа тақырыптар қосылғаннан кейін де сақталады.

Оқу мысалдарын нақты орындап салыстыру үшін Python 3 және JDK 17+ керек:

    npm run verify:examples

Python/Java орындалатын файлдары PATH-та болмаса, QADAM_PYTHON, QADAM_JAVA және QADAM_JAVAC орталық айнымалыларын орнатыңыз. Тексергіш тек жоба авторлары дайындаған 105 мысал мен үлгі шешімді орындайды; оны қолданушы кодын орындайтын API ретінде қолдануға болмайды.

Нақты орындалған тексерулердің нәтижесі TEST-REPORT.md ішінде.

## Ағымдағы шектер

Профиль мен прогресс localStorage ішінде, осы браузерде сақталады. Атты өзгерту нақты аккаунт құрмайды, құпиясөз жиналмайды.

Сабақтағы кодтың шығысы — көрсетілген кіріске арналған тексерілген күтілетін нәтиже. Сайттағы код редакторы нобай жазады және сақтайды. Қолданушы кодын орындау, автоматты код бағалау, серверлік оқу аккаунты және нақты достар әлі қосылмаған. Онлайн пинг-понг нақты екі ойыншыны бір бөлмеде қосады; Python бөлімі жеке дайындық тесті болып қалады.

Рейтинг пен достар — анық белгіленген үлгі деректер. Оқу сұрақтарының жауаптары ашық материал; олар сервердегі жасырын код тесттері емес.

## Жариялау

Жариялауда Vinext/Cloudflare Worker және D1 пайдаланылады. Sites конфигурациясы .openai/hosting.json ішінде; project_id сақталады. Тек статикалық хостинг ойын серверін іске қоспайды.

    npm ci
    npm run build

Схема өзгергенде алдымен npm run db:generate орындалады. Жасалған SQL және Drizzle журналын Git-ке қосу керек; бұрын қолданылған миграцияларды өзгертпеңіз. Sites жариялау кезінде D1-ді қосып, миграцияларды қолданады. Жинақталған Worker-ді жергілікті тексеру үшін npm start, ал framework әзірлеу сервері үшін npm run dev:hosting бар.

Болашақ API үшін .env.example бар. Қазіргі статикалық сайт ол мәндерді пайдаланбайды. Нақты орындау сервисі қосылғанда оның құпия кілттері тек серверде сақталуы керек.
